# Model — how the world works

Living document for the core working principle. Settled parts become decision
records. Learning is a **separate, later stage** ([ADR-0004](decisions/0004-what-ml-means.md));
for now every rule is written by us.

## North star

**Emergence and environmental storytelling.** Nothing above the leaves is
authored; every house, village and ruin has a recorded cause you can read.

## The cast

| Character | When | Job |
|---|---|---|
| **Archie** (architect) | before and during a run | loads, checks and updates packs: the types and rules of the world ([ADR-0018](decisions/0018-archie-and-packs.md)) |
| **Noah** | at the start | defines the space, places the first leaves and knowledge; the user configures Noah ([ADR-0017](decisions/0017-noah-genesis.md)) |

| **People** | while running | act on their goals and knowledge |

A world = Noah's configuration + seed + loaded packs.

## Principles (settled)

1. **The space is the root.** Everything lives in a space carrying **fields**
   (height, water, fertility, soil, temperature, …). Fields are continuous
   properties of the space; **things** (trees, stones, people) are not fields but
   leaf nodes in the graph, positioned in the space. ([ADR-0006](decisions/0006-space-fields-leaf-input.md))
2. **Outside input only at the leaves.** Leaves are people, stones, trees, tools…
   Nothing derived (a house, a village) can be placed or popped into existence;
   it must emerge through a process. ([ADR-0006](decisions/0006-space-fields-leaf-input.md), [ADR-0008](decisions/0008-people-needs-construction.md))
3. **One source of truth.** Every value lives in one place; the rest is computed. ([ADR-0005](decisions/0005-node-graph-and-actualizer.md))
4. **Story and form share the space.** The graph says what exists; the actualizer
   gives it form and cannot contradict it. ([ADR-0005](decisions/0005-node-graph-and-actualizer.md))
5. **People are the decision makers.** Things get built because a person needs
   something and acts on it. ([ADR-0008](decisions/0008-people-needs-construction.md))
6. **Derived nodes are composite.** A house is many parts (walls, windows,
   blocks) folded into one node. Its internal parts are generated by the system,
   WFC-style, together with the actualizer. ([ADR-0009](decisions/0009-composite-nodes-typed-edges.md))
7. **Measurable values are derived; unmeasurable ones are relative.** ([ADR-0010](decisions/0010-value-kinds.md))
8. **Chances are normalised (0–1), countable things are counts.**
9. **Time is an event queue** with lazy continuous values and threshold events;
   people are woken by the queue. ([ADR-0007](decisions/0007-time-model.md))
10. **Molly** (the world's keeper) recognises and names what forms, defines concepts (a house
    concept) and influences people (night → fear). Entropy handles growth,
    drought, wear, ageing and knowledge drift (ADR-0021). People do the work. ([ADR-0012](decisions/0012-the-system.md))
11. **One write channel.** Every change is an event; the history is the event
    log. Engines (scheduler, rules, WFC, …) are a technical layer. ([ADR-0013](decisions/0013-layers-and-communication.md))
12. **People:** decide by utility scoring (best fuzzy μ wins) for now, GOAP once
    knowledge nodes exist; released into the world at the start, born later.
13. **Edges work both ways:** stored once, queried from either end, and each end
    may carry its own data.
14. **Knowledge nodes.** The world is the single truth; what people know is held
    in typed, shared, immutable knowledge nodes (claims) that many people link to.
    People act on knowledge: a tree must be known before it can be used. Claims can
    be stale; sharing a claim is adding a link. ([ADR-0015](decisions/0015-movement-perception-memory.md), proposed)
15. **Weighted goals, never one target.** A person always holds several goals
    with weights and priorities (survive, have children, build a house) and
    re-scores on every event: carrying wood home, a bear comes into view, flee.
    **Determination** keeps them on their task against some risk, so they don't flip-flop.
    ([ADR-0016](decisions/0016-mind-weighted-goals.md), proposed)
16. **Outside input only through Noah**, and only leaves and knowledge. ([ADR-0017](decisions/0017-noah-genesis.md))
17. **Everything is a pack.** The engine knows no houses; types, rules and parts
    come from packs that Archie checks. Packs are data run by our own interpreter,
    never code. Packs can be loaded mid-run (as an event). ([ADR-0018](decisions/0018-archie-and-packs.md))
18. **Three node kinds: entity, knowledge, mind**, with "shared node, personal
    edge" for knowledge and mind. Villages and house concepts are entities; events
    stay in the log; names given by peoples are knowledge, so the same river can
    have different names. ([ADR-0019](decisions/0019-three-node-kinds.md))

## Layers

```
 Space (root) ── fields: height, water, fertility, soil … (properties, not things)
   │
   ▼
 Node graph (story)
   leaves (placed from outside): Person, Tree, Stone, Axe …
   derived (only via processes):  Construction → House ─ parts: walls, windows …
                                  Houses together  → Village → Town → …
   typed edges: Person ─uses→ Axe, Person ─livesIn→ House, Wall ─partOf→ House
   │
   ▼
 Actualizer ── physical form; works with the composite-part layer (WFC)
```

## How things come into being

Three mechanisms, none of them "place it":

| Mechanism | Driven by | Example |
|---|---|---|
| **Action** | a person meeting a need | needy person + material + buildable spot → Molly places a house **concept** → the person **works** to turn it into a `House` → `Person ─livesIn→ House` satisfies shelter |
| **Aggregation** | fuzzy clustering | houses close together on fitting land → `Village` |
| **Composition** | the derived node itself | a new `House` gets its walls, windows, floor laid out WFC-style |

### Action: the fuzzy triple

```
μ_build = AND( needs(person, shelter), knows(materials nearby), suits(spot) )
```

- The person's need is measurable (derived from their state).
- Materials are leaf nodes in the graph (trees, stones), positioned in the space.
  Fields only influence them (fertility decides where trees regrow).
- The spot is read from the fields (flat, dry, not taken).
- Building is a **process over time** (`Construction` node), not an instant.
- Later: the person must also **know how** to build (knowledge nodes). Skipped in the first stage.

### Aggregation

```
μ_village = AND( many(houses), close(density), suitable(fields) )
```

Forming needs a higher μ than dissolving (hysteresis).

## Node

| Field | Meaning |
|---|---|
| `id` | stable; seeds every random choice about this node |
| `type` | leaf types can be placed; derived types only emerge |
| `position` | where it is in the space |
| `values` | measurable (counts, damage, needs) or relative (happiness) — see ADR-0010 |
| `edges` | typed links: `partOf`, `memberOf`, `uses`, `livesIn`, … |
| `history` | events that touched it (the root of personal stories) |

Groups and composites act like a single node in rules, so the structure is a
**graph, not a tree**.
